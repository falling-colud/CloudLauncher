# Security

If you find a security problem in CloudLauncher, the launcher or the service at
cloudlauncher.co, please report it privately by e-mail to contact@cloudlauncher.co rather than
in a public issue.

Please include:

- what the problem is and what someone could do with it,
- the steps or a small proof of concept to reproduce it,
- the launcher version (Settings > About) or the address involved.

You should get a reply within a few days. Please give me a reasonable amount of time to fix
the problem before you talk about it publicly. Testing is fine as long as you only use your
own accounts and data, and you don't degrade the service for other people.

Only the latest release of the launcher gets security fixes. The launcher updates itself, and
updates are signed, so a fix reaches everyone quickly.
